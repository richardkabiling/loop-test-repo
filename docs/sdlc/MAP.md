# Doc map

Read this to find the right doc before searching. Each line says when to read the doc.

| Doc | Read when |
|---|---|
| `docs/sdlc/LOOP.md` | You need the loop's phases, gates, strategies or deliverable methods |
| `REVIEW.md` | You are reviewing a change, or preparing one for review |
| `docs/sdlc/personas.md` | You run a persona review (intent, design or build) |
| `docs/sdlc/lenses/` | You are a lens reviewer: read only the lens file you were given |
| `docs/sdlc/REPO_MAP.md` | You are orienting in unfamiliar code: which files matter and what they export |
| `docs/sdlc/research/` | You change the loop, a convention or a harness component: check earlier research first |
| `docs/sdlc/improve/` | You run `/charmander-improve`: earlier findings and their dispositions |
| `docs/decisions/` | You change architecture, a public API, infrastructure or a cross-cutting convention: check existing ADRs first |
| `GLOSSARY.md` | You name things or meet unfamiliar domain terms |
| `docs/ops/tech/` | You change infra, deploys, alerts or the API's runtime behaviour: update the tech ops manual in the same PR |
| `docs/ops/business/` | You change a business process, admin procedure or support flow |
| `api/openapi.yaml` | You touch the HTTP API or the frontend's data access: the contract comes first |
| `docs/work/` | You resume a work item: intent, spec, design, plan, tickets, progress |
